Descargador DIAN

Descarga en lote los PDF de documentos electrónicos de la DIAN a partir de una lista de llaves CUFE/CUDE. Usa un navegador real; si Cloudflare pide un clic, resuélvelo en la ventana que se abre y la descarga continúa automáticamente.

1 · Lista de CUFEs

Sube un .xlsx con las llaves. Se autodetecta la columna CUFE/CUDE; si el archivo trae además Tipo de documento, Prefijo y Folio (como el reporte de la DIAN), se usan para nombrar cada PDF. Puedes usar el mismo reporte de documentos electrónicos.
